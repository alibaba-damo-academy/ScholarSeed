# Skill Center Evaluation

Read the [product Skill contract](../../../docs/architecture/skills.md) and [evaluation architecture](../../../apps/desktop/docs/architecture/evaluation.md). Record the exact Skill ID, revision, target product, input, expected evidence, and adopted evaluation criteria supplied for the task. Missing criteria block scoring.

Use the selected and authorized product UI or API mode. Confirm the expected Skill is installed and enabled, then run the selected case once in its assigned test environment. Observe the real terminal state, capture public turn and tool evidence and permitted output files, and report missing evidence. A read-only follow-up checks the existing session without sending another request.

Review evidence against the adopted checklist. Keep any authorized offline reference score separate from formal admission. Preserve the evaluated product, baseline, and criteria.
