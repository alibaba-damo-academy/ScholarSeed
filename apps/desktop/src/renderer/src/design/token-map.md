# DeepRD 到 Veda Token 映射

本页是初期迁移来源映射，不是当前 token 库存或样式技术栈规范。开发时先读
[视觉基础规范](../../../../docs/design/foundations.md)，再查询真实 `design/*.css`
及[生成库存](../../../../docs/_generated/tokens.md)。下表“已迁入”记录初期处理，
不证明各值仍与来源相同、完整覆盖当前变量或主题已实机验收。

当前 `styles.css` 已导入 Tailwind，Desktop PostCSS 使用 `@tailwindcss/postcss`；
不能沿用初期“不引入 Tailwind”的判断，也不能据此授权重新导入供应商整份主题。

## 初期迁移规则

- DeepRD `--ds-*` 统一迁移为本工程 `--vds-*`。
- DeepRD `.dark` 主题入口统一改写为本工程 `:root[data-theme='dark']`。
- 新代码只允许使用 `--vds-*`，不允许继续新增 `--ds-*`。
- 初期未迁入来源的 Tailwind `@theme`、`@plugin`、`@custom-variant`；当前样式规则由视觉基础规范持有。
- 来源 `markdown.css` 的暂缓是初期范围记录，不代表当前所有 Markdown 渲染能力仍待实现。

## 特殊映射

| DeepRD token | Veda token | 来源文件 | 目标文件 | 状态 | 备注 |

| Tailwind `@theme` | - | `platform_frontend/src/styles/theme.css` | - | 初期未迁入 | 当前已接入 Tailwind；来源主题不可据此整份恢复 |
| `markdown.css` | - | `platform_frontend/src/styles/markdown.css` | - | 暂缓迁入 | 等业务页面需要统一 Markdown 渲染时再处理 |
