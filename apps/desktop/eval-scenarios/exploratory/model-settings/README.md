# 模型设置：候选 A 类探索场景

方向 `MODEL-01@2`，关联 `MODEL-CONFIG-01@2`（P1）与只读 `MODEL-CATALOG-01@1`（P2）。不新增默认 P0，不把目录可见、内置模型显示或空密码字段当作新服务配置成功。暂无获批正式 PRD/Check，全部预期为候选。

按钮、模型名称及静态文案只作本次观察线索，未经批准不成为精确文案要求或未来唯一 locator。后续改名先记录差异并核语义身份；无法确认时给 `inconclusive`，不只因旧名称消失判失败，也不改变按目标结果的候选功能判据。

只读目录与真实配置是独立分支。只读分支通过头像菜单的设置打开模型服务与模型配置页，记录实际名称、计数及控件状态，不输入密钥、不探测、不保存或启停。真实配置分支必须另有获准端点、专用临时密钥、配置写入及外部探测授权；由获准操作者输入凭据，不从用户 Home、配置、日志或另一实例提取秘密，不将凭据值写入截图、运行记录或资产。缺少任何专用前提时完整配置仍为 `partial`，相关 Check 为 `not_evaluated`，只读观察不能抵消缺口。

本轮六域探索只读到达模型服务目录、厂商空编辑表单和内置模型配置页，未输入密钥、测试连接或保存服务。空字段的 `type=password` 不能证明真实密钥的输入、保存、回显或全生命周期安全；实际事实与证据索引由 Desktop 业务用例及本轮忽略快照持有，本文不是通过记录。

沿用 `scenario.json`、`cmd.jsonl`、`baseline.json` 与 Driver/Judge/Check 映射。`cmd.jsonl` 只有状态预检，不是设置 UI runner，既不配置服务也不发连接请求；真实操作由获准 desktop-control Driver 按当前 UI 驱动。`auth=none` 只表示无预置登录要求，不绕过产品自己的身份和权限。零产品模型回合不代表连接探测无网络或无费用；探测仍须独立授权。

运行前冻结来源、构建、平台、隔离配置、动作/网络范围与停止条件。`MODEL-SAVE-SELECT`、`MODEL-KEY-REDACTION` 只属于真实配置点，`MODEL-CATALOG` 只属于只读目录点；按本轮所选点冻结 Check，不用目录检查替换配置结果。所有项为 A 类，交 Observer/测试 Owner 核可见终态与实际检查截图，无需语义模型。原始截图和操作证据只保存到获准忽略目录；macOS 观察不证明 Windows 或其他账户态。
