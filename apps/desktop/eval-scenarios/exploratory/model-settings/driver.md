# Driver 可见任务

只读取本文件、本轮授权参数与实时 UI，不读取 `judge.md`。仅操作已核身份的本轮隔离 Desktop，不读取用户凭据或其他实例配置，不发送产品模型对话。只执行本轮明确选择的分支。

只读目录任务：通过头像菜单打开设置，进入模型服务。记录当前厂商目录、启用计数及可见控件状态；再进入模型配置，记录实际内置模型名称及显示开关的 checked/disabled 状态。不要把勾选或可见目录解释为可调用，不点击保存、启停或连接探测。关闭设置，保存实际观察与已检查截图；不要求将本次名称和计数固定为未来结果。

真实配置任务：先核本次配置写入、专用端点与临时密钥、真实外部探测及费用授权；缺少任一前提即停止该分支，不读取或借用现有真实密钥，不为观察而保存空配置。只有获准操作者可通过产品可见表单输入本次专用凭据，按当前 UI 测试连接、选择目标模型并保存，再重新打开同一服务及可选模型目录，记录实际保存与模型身份。界面权限或服务错误按实际状态交接，不重试到绿或擅改服务。

密钥观察只记字段是否遮挡和所处步骤，不提取、回显、截图明文密钥或验证码，不访问存储来证明安全。空 password 字段只记录为空字段；不代表真实密钥保存后安全。若敏感内容可能进入截图，停止采集并说明证据缺口，不扩大读取或更改用户配置。保留本轮范围与终态，不作通过判定；窗口到界停止新动作及外部请求。
