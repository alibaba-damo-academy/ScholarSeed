# MODEL-01 候选判据：A 类事实核验

无获批正式 PRD/Check；冻结本文件后由 Observer/测试 Owner 按实际所选点核验，给 `pass / fail / inconclusive / not_evaluated`、理由和原始证据。本文件不交给 Driver。没有新密钥或连接授权时不运行完整配置；只读目录点不依赖真实配置成功。

1. **MODEL-SAVE-SELECT｜A：保存后目标模型可选（必需）**。在本轮专用端点、临时密钥和外部探测明确获准的前提下，经真实产品表单完成连接、选择和保存，重新打开同一服务可关联已保存配置，目标模型进入客户端可选目录。明确保存错误、配置错位或成功保存后目标模型仍缺失为 `fail`；只见连接提示、内置模型、目录或空编辑表单为 `inconclusive`；未获专用凭据/探测/写入权限而未执行时为 `not_evaluated`，不能借其他实例连接结果补证。
2. **MODEL-KEY-REDACTION｜A：本次真实凭据无明文回显（必需）**。本次实际输入、保存并重新打开的专用凭据，在被观察的产品字段与结果界面均不以明文显示；证据只记录遮挡状态与步骤身份，不保存密钥值。明确明文回显为 `fail`，暂停敏感画面采集并按获准渠道报告；已执行但缺关键步骤证据为 `inconclusive`；未实际输入并保存专用凭据为 `not_evaluated`。空 password 字段、占位符或已遮挡的账户手机号不能证明本项，也不推断底层存储加密、请求日志安全或完整密钥生命周期安全。
3. **MODEL-CATALOG｜A：只读模型服务与内置目录（必需）**。真实头像设置入口可打开模型服务与模型配置页，当前厂商目录、实际启用计数、内置模型名称及显示控件状态有同实例证据；不要求未来固定计数、厂商状态或模型名，不要求编辑、连接、保存或发模型请求。可见目录与实际选择页面错位、明确无法展示本应可访问目录为 `fail`；只有入口或单页证据不足以核对两页为 `inconclusive`；因权限/前提未到达为 `not_evaluated`。目录存在或 checked/disabled 状态不证明模型可调用，也不能替代前两项。

按本轮选择的稳定点汇总其必需 Check，保留未执行及证据不足，不用只读项通过覆盖配置缺口。所有结果均限本轮构建、平台和账户态；候选判据和单次 A 类事实不形成正式发布覆盖。
