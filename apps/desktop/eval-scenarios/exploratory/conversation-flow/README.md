# 对话可执行：探索性业务评测

方向：`CHAT-01`。目标是在真实 ScholarSeed Desktop 中发送一个有明确研究场景的普通问题，取得可用且切题的完整回答。首轮短评测只要求**一轮**；同会话追问是可选扩展，不计入首轮通过分母。暂无获批 PRD/Check，本场景不能计入发布覆盖；`baseline.json` 是待验证的候选期望，不是通过记录。

本目录沿用 [场景库格式](../../README.md) 的 `scenario.json`、`cmd.jsonl`、`baseline.json` 三件套。`cmd.jsonl` 只作预检；真实 Driver 按观察在本次忽略运行副本追加操作，不把固定等待或 `ack.ok` 当作回合完成。`driver.md` 只给用户可见任务，`judge.md` 只供隔离的独立 Judge 与人工复核。

运行前冻结方向行修订、场景 Git commit、目标构建身份、平台、实际模型及账号态，核对隔离 Home/profile、产品会话范围和产品/Driver/Judge 的预算与停止条件。第一档 P0 的业务评测开始到报告不超过 30 分钟是整批方向的目标，不是本场景保证；准备阶段的下载、校验、安装与首启不计入该 30 分钟，准备及总耗时另报。按 [执行入口](../../../../../.agents/skills/llm-evaluation/SKILL.md#batch-与-report)在首个必需业务动作前记录 T0，不能预先发送本场景问题再起表；T0 后的等待、修复、取证和评审报告均计时。到界停止新增模型调用，保留已发生的失败与未评测项，历史运行不回改。

由真实界面打开 AI 对话，发送 [driver.md](driver.md) 的首轮消息。记录输入、完整回复、产品 `session_id`/turn、动作 seq、终态、截图及必要 Trace 指针；`running=false`、发送按钮恢复、空白答复或仅有进度动画都不足以证明完成。按 [judge.md](judge.md) 区分执行状态与语义质量；若身份或正文不完整，给 `inconclusive`，不复用另一会话证据。只有本轮已正常完成且预算允许时才尝试可选追问。
