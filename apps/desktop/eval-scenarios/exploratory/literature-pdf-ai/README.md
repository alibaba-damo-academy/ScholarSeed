## 业务范围

用户从**文献全览**导入一份本地 PDF，打开其文献附件，在真实 PDF 文字层选中“Pilot summary”整段，分别使用选区“解释”和“翻译”动作。首轮只测这一页、这一段的解释和中文翻译；全文解读、全文/逐页翻译、图表识别、文献检索与资料库 PDF 属于其他路径，不由本场景结论外推。

`fixtures/note-retrieval-pilot.pdf` 是一页、可选中文本的合成资料，不含用户数据。唯一目标资料为该 PDF 字节及导入后同一文献条目的附件；导入后生成的题录标题可能经过自动提取，不以标题完全相等作为准入。每次运行先记录 fixture SHA-256、导入后文献 ID、附件 ID、来源版本及实际项目/全局作用域，确保解释和翻译针对同一 PDF 字节。

## 文件职责

- `scenario.json`、`cmd.jsonl`、`baseline.json` 沿用现存三件套。`cmd.jsonl` 只有状态预检；真实 UI 操作按观察追加到本次忽略的运行副本。`--drive` 不解析本描述，也不会导入 PDF。
- [driver.md](driver.md) 只给独立 Driver 用户可见目标与操作边界；[judge.md](judge.md) 为独立 Judge 和人工复核的候选判据，不交给 Driver 或导入产品。
- `fixtures/` 是唯一资料真源。运行时复制到本次隔离目录，用产品可见的本地 PDF 导入入口选择副本，保留原件只读。
