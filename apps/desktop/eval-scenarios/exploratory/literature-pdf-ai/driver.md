# Driver 可见任务与操作边界

只使用本文件、真实 ScholarSeed Desktop 界面及本次运行的观察。不要读取 `judge.md`、宿主中的 PDF 正文或隐藏参考；选区文字必须从产品的 PDF 阅读器观察。若当前上下文已读过隐藏判据，应由未接触它的独立 Driver 执行。

Observer 应先交付本次获准的精确构建、隔离环境、fixture 副本路径和摘要、允许动作及预算。运行副本中的 `cmd.jsonl` 初始只有 `status`，它不能证明文献身份。未核对本次版本和实例时不发送模型请求。
同时交付冻结点位/档位：P0 执行打开、解释和翻译的真实功能路径；P1 质量点对同一次动作结果复用，不额外调用模型、不重新生成或更换输入以获取更好答案。Driver 不判断语义质量，交独立 Judge；授权不足立即停止相关动作，其他独立就绪点继续。历史运行不按新档位回填结论。
每次 AI 提交前确认 Observer 已就绪，可记录本次原请求、回执及精确 task 的终态完整结果；
只读结果暂不可达时交还编排者记录缺口，不自行发送额外请求、改模型或重新生成来补证。
开始前确认本次预算允许一次选区翻译调用；选区入口没有提交前的目标语言控件，
不要把界面语言、全文翻译设置或提示词设置冒充选区翻译的目标语言。

1. 打开**文献全览**，从可见的“导入本地PDF文件”入口只导入一次本次提供的 `note-retrieval-pilot.pdf` 副本。等待导入终态并读回条目与 PDF 附件身份；选择器或回执不明时先观察状态，不再点击导入或自动重试。不要将同名资料库文件或内置新手示例当作这份文献附件。
2. 由条目或附件入口打开 PDF；确认阅读器显示一页真实内容，文字可以选择，且“Pilot summary”段属于这份附件。记录文献 ID、附件 ID、页码及打开状态。导入或打开失败时停止 AI 动作，报告阻塞/错误。
3. 选中“Pilot summary”下从 “Twenty-four volunteers” 开始的完整英文段落。点击前记录产品中可见的完整选区原文、页码和附件身份，提交后让 Observer 冻结实际请求/回执。使用选区工具的“解释”，在补充要求中输入：`请用中文解释这段研究设计、观察结果和证据局限，区分观察到的事实与不能据此推断的因果结论。` 提交后观察任务终态与完整解释结果。不能用右侧“全文解读”按钮替代本次选区动作。
4. 在**同一文献附件**确认仍选中同一整段；选区未保留时重新选择并冻结原文，不能仅凭上一动作推断。只触发一次获准的选区“翻译”，随后由 Observer 读回实际请求的 `target_language`、选区原文、附件身份、任务终态和完整译文；不能用界面语言推断请求目标。若目标不是简体中文，按判据记录失败；读不回则记录缺证。不要在结果浮窗改语言或重新生成来覆盖首轮结果；另获准重试时另记 attempt 和费用。不能用全文/逐页翻译或对话消息代替本次选区翻译。

解释和翻译各自遵守[切页前：完成可见结果采证](../../../../../.agents/skills/llm-evaluation/references/results.md#切页前完成可见结果采证)。解释结果采齐后才关闭浮窗并开始翻译；翻译结果采齐后才离开 PDF。Observer 须交回本动作已保存且已打开检查的截图、可见结果和精确任务文件路径；后台 completed 不代表译文已在界面显示。不能先转去其他业务方向、最后才回头补结果图。采证受阻时先冻结本项缺口，再继续独立点，不为补图重新触发模型。

每次动作前确认当前选区原文非空且属于目标 PDF；已有解释浮窗遮挡时在其采证完成或已冻结缺口后按界面正常方式关闭，再重新选择。任何权限请求只按本次授权处理；未知范围停止并交给用户。保存两次动作各自的原始结果、任务状态、截图及来源身份；不由宿主改写结果，不以固定等待、`ack.ok` 或 `running=false` 推定完成。不要自动重试、添加批注、复制到项目或改动原 PDF。
