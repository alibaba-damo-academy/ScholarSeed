# 文献全览 AI 对话发现新文献：探索性业务评测

方向：`DISC-01`。用户已指定入口为**文献全览中的 AI 对话检索**。目标是从该可见入口发起真实外部文献发现，展示可核对的新题录及其与研究问题的关系。这里的“新”指运行前当前隔离文献库中不存在；不要求论文刚发表，也不要求下载全文、导入文献库或完成长篇综述。暂无获批 PRD/Check，本场景不能计入发布覆盖，`baseline.json` 仅是候选期望。

不要使用目前隐藏的文献全览专用发现搜索框，也不要把列表筛选已有文献当成发现。按 [场景库格式](../../README.md) 保留 `scenario.json`、`cmd.jsonl`、`baseline.json`；预置 `cmd.jsonl` 仅含状态查询，不会自动执行导航、检索或建项目。`driver.md` 是 Driver 可见投影；`judge.md` 仅供独立 Judge。

运行前冻结方向行修订、场景 Git commit、目标构建身份、平台、实际模型、账号态和隔离 Home/profile。记录产品/Driver/Judge 预算、外部检索网络可用性、起始确认及停止条件。第一档 P0 的业务评测开始到报告不超过 30 分钟是整批方向的目标，不是本场景单独的耗时保证；准备阶段的下载或缓存复核、校验、安装与首启不计入该 30 分钟，准备及总耗时另报。按 [执行入口](../../../../../.agents/skills/llm-evaluation/SKILL.md#batch-与-report)在首个必需业务动作前记录 T0，业务与取证不前移，等待和修复不重置窗口。T0 后、检索前通过真实产品 UI 或公开只读接口保存全局文献库快照（至少题名、DOI/arXiv ID、库身份与采集时间）；空库也要读回证明，不能靠“新 Home 应该为空”推断。到界不开始新步骤，保留已观察结果与未评测项，历史运行不回改。

从文献全览打开 AI 对话，在同一可追溯的产品会话中提出 [driver.md](driver.md) 的元数据发现任务。若产品选用“精准检索”技能，其专属澄清与开始确认必须按产品真实交互处理；本场景可授权元数据检索，**不授权全文下载、阅读或入库**，遇到超范围授权停下。不能由宿主 shell/搜索工具代替产品检索。记录会话/turn、可见候选或结果卡、底层检索任务/来源及其身份、回复与截图，必要时用 Trace 核真正发生外部检索。

独立 Judge 按 [judge.md](judge.md) 核对题录、检索前库状态与相关性。在线源未能核验或产物未到可见阶段时，不凭模型自述判通过；把 `fail`、`inconclusive`、`not_evaluated` 与运行 `blocked` 分开。查询时段、网络索引和外部平台可能改变候选集合，因此不规定固定篇名或数量超出最小一篇。
