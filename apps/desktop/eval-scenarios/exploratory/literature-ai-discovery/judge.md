# DISC-01 候选判据：独立 Judge 与人工复核

暂无获批 PRD/Check。运行前冻结本文件版本；对每项给 `pass / fail / inconclusive / not_evaluated`、理由与原始证据指针。本文件不交给 Driver 或被测产品，也不预置要返回的篇名。

1. **DISC-ENTRY｜入口与真实检索（必需）**。任务从文献全览的可见 AI 对话入口发出，用户问题、产品 `session_id`/turn、检索任务或工具/来源证据可关联到目标构建。仅列表本地筛选、隐藏专用搜索框、历史已有卡片、语言模型凭记忆列举论文，均不通过。产品显示检索开始但无可见候选时，该项最多 `inconclusive`，发现项为 `not_evaluated`。
2. **DISC-NEW｜新题录可见（必需）**。至少一篇候选在本次会话回复或其结果卡中真实可见，含完整题名、可识别作者/年份、DOI、arXiv ID 或出版方可访问页面之一；与检索前**同一全局库**快照对照，按 DOI/arXiv ID 优先、规范化题名辅证，至少一篇原先不在库中。无法获取检索前快照，不能证明“新”，判 `inconclusive`；原先已在库中且没有其他新候选则 `fail`。可见候选不自动等于已下载或入库。
3. **DISC-SOURCE｜来源真实性与业务相关性（必需）**。独立从 DOI 注册机构、arXiv、出版方或其他论文原始落地页核至少一篇的题名、作者/年份及身份；判读其研究确实讨论 RAG 评测方法或基准，而不是仅提及 RAG。允许候选列表随索引时间变化，不要求固定论文。链接打不开或元数据不足以交叉确认时记 `inconclusive`，伪造题录或与主题明显无关记 `fail`。引用数量和关键词不是语义判定。
4. **DISC-BOUNDARY｜边界与证据（必需）**。产品没有在本次授权外下载全文、入库、修改文献或读取无关项目；记录真实消息、产物、来源、身份、终态/当前阶段、动作和截图，明确缺失的 Trace 或截断正文。因产品技能需要明确开始确认而 Driver 未获准确认，应报告 `blocked/not_evaluated`，不得把未执行说成失败或通过。

全部必需项 `pass` 才给场景 `pass`；明确违反给 `fail`；无失败但关键证据欠缺给 `inconclusive`；未开始或未到可判阶段给 `not_evaluated` 并说明执行状态。报告须注明真实外部源可能变动，不能拿一次候选结果当作长期检索召回率保证。
