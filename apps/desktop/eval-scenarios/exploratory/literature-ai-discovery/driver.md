# Driver 可见任务

只看本文件、产品界面和本次真实运行观察，不读取 `judge.md`。在隔离 Desktop 中进入**文献全览**，确认当前不是项目内文献库；必要时打开可见的 AI 对话面板（`topbar-ai`）。保存此时文献库的只读快照证据和范围；专用发现搜索框与列表筛选都不是本任务入口。

通过文献全览 AI 对话发送：

> 请通过文献检索，找 1 篇 2023 年以来关于检索增强生成（RAG）评测方法或基准的研究论文。展示可核对的题名、作者、年份、DOI／arXiv ID 或出版方页面，并用一句话说明为何相关。这次只做题录发现，不下载全文、不加入文献库、不写综述。

逐步观察产品回复、澄清、确认和候选/结果卡。若产品要求确认开始**元数据检索**，在本次获准范围内按产品提示明确答复；若要求全文获取、浏览器/网站登录、超范围网络操作或其他未知授权，停下记录，不自行放宽范围。不要预先选定技能工具调用，不由宿主提供论文名单或代替产品执行搜索。

至少保存一篇真实可见候选的题录、来源标识、与问题相关的理由，以及产品会话/turn、检索/产物身份、动作 seq、终态或当前阶段、截图。若流程在候选展示前停止，原样报告 `not_evaluated` 或 `inconclusive`，不把“正在检索”、固定等待结束或模型自述当作发现成功。
