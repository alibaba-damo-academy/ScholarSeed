# 第三档配套资产与准备交接

本次只准备原默认第三档74个业务点（P0 10、P1 31、P2 33），不是全部44条P2手工用例，也不加入表外方向或P3。唯一业务点仍在[目录](../../../docs/scenarios/catalog.json)，六分片保存手工用例；不新增ID、不调级、不改产品业务逻辑或规则。此前P0/P1的任务及Check正文保留，受影响方向行只因新增P2判据或链接递增修订。

## 输入与分母

- 复用[P1准备约定](../p1-assets/README.md)及原四格式输入；本目录只补30个原缺口点所需的公开合成输入，不复用历史业务结果。
- 每点选一个主用例；同点必需分支单列执行映射：已有目录接入的确认与取消、名称/类型/来源筛选、DOI/arXiv、BibTeX/RIS、版本数量/单文件大小、全局搜索三个业务域分别判断。不能只测一分支就让整个点通过。
- 三件套的status仅诊断，不是自动runner。Driver按所属场景driver.md执行；judge.md是独立判据，不交给Driver。执行前只复制公开输入到忽略目录并核摘要，不能把项目创建、导入或模型动作提前到免费准备阶段。
- `manual_ready`表示人工资产有入口、任务、候选判据与输入约定，不表示当前实例/授权/真实前提已就绪或平台通过。来源仍pending、预期仍candidate_unapproved，不晋升正式覆盖。

## 合成输入

| 输入 | 用途与独立性 |
| --- | --- |
| `source/移动前.md`、`source/副本原件.md` | 重命名、移动、副本各用独立副本，保存源及目标SHA；不能用宿主文件操作完成产品任务 |
| `linked/事实.md` | 外部关联专用目录，正文LINK-EXTERNAL，核原件保护与真实关联模式 |
| `P2-SEARCH-TOKEN.md` | 名称搜索及跨域资料命中；近似名对照见下一行 |
| `P2-SEARCH-CONTROL.md` | 对照正文与名称均不含完整TOKEN标记 |
| `bibliography.bib`、`bibliography.ris` | 两格式各两条不同合成题录，避免去重或上一格式成功遮盖当前导入失败；BibTeX ALPHA题名含搜索标记 |
| `identifiers.json` | 两个不同公开标识及事前参考定位；只允许元数据访问，下载全文需另授权 |
| `outline.pdf` | 两页可选英文文本、两个大纲条目；第二页有独立标注目标，不借用资料库PDF代替文献附件 |
| `threshold/1023.txt`、`1024.txt`、`1025.txt` | 1KiB单文件版本策略边界输入；不是批准产品默认值，不将阈值当历史总容量 |

二进制PDF与字节边界资料由[fixtures.mjs](fixtures.mjs)确定性生成并检查。生成是离线合成输入，不等于已通过产品导入。各场景descriptor只声明依赖，仍需未来运行物化与核对。

## 执行前冻结的非秘密参数

| 前提 | 必须准备及不足时处理 |
| --- | --- |
| 实例 | 目标包/构建、平台、签名、精确PID、全新Home/profile/workspace及共享状态风险；不得操作日常实例或复制登录凭据 |
| 任务对象 | 唯一run标签，A/B项目、归属明确的资料/文献/session稳定ID；项目、导入、保存等真实动作计入本轮业务窗口 |
| 原生入口 | desktop-control现有原生选择/提交能力；精确PID系统输入需本次授权；选中不等于提交、关闭面板不等于导入完成 |
| 设置 | 思考强度、上下文、版本策略分别核配置隔离、原值、合法替代值、变更回执及恢复路径；不能确认隔离则不改设置 |
| 版本策略 | 必须事前核数量计数语义、大小单位和等号边界来源，冻结精确范围、阈值、期望和清理授权；不把当前表现或源码自动当批准需求。当前资产提供候选检查及样本，缺批准语义或共享清理范围不明则阻塞策略Check，不临场补判据 |
| 账户/模型/Zotero | 仍复用P1的专用身份、可信服务临时密钥和合成Zotero库前提；本轮资产维护不创建账号、密钥或授权登录。已有登录显示不能代替真实登录Check |
| 外部访问 | 标识导入与公开发现分别核本次权限，内部联网不等于用户触发AI；不要将文件导入失败自动重试或下载全文 |
| 模型预算 | 完整P0/P1原动作预算另核；P2新增排队两次用户消息，历史搜索/分支/全局会话搜索复用本轮既有已完成消息，不额外生成。首条排队消息固定追加P2-SEARCH-TOKEN再冻结；无running窗口不自动重发。此处是预算输入，不是调用授权 |
| 语义评审 | P2新增均为A观察，不另造B Judge；既有P0/P1的B/mixed仍需独立Judge，不由确定性管理检查代替 |

版本策略的候选判据不是空白参数：数量为每文件最新2个已封闭历史版本，大小为1024字节、等于阈值准入，超出不准入；先核.txt已纳入版本管理。线索为[数量影响计算](../../../../serve/service/resources/service/retention.py)、[大小准入](../../../../serve/service/resources/domain/policy.py)及[数量契约](../../../../serve/tests/contract_resource_retention.py)。这些源码只解释候选来源，不自动晋升产品需求；未来本轮采用确认与精确清理授权仍须单独核对。Driver只获得公开操作和参数，不能读取judge正文后自评分。

## 有界顺序与依赖

1. 原P0/P1准备项目与资料，通过正常业务路径形成所需对象。独立输入分组互不污染，不依赖上一attempt结果。
2. P2资料点在专用父目录独立执行；新建目录失败不阻断可使用冻结备用父目录的重命名、副本等独立点。备用父目录必须执行前记录，不临时补资产。
3. BibTeX与RIS分开导入，各自记录前后水位；ALPHA/BETA作为列表、分类、标签、笔记的明确前提。某格式导入受阻，另一格式仍执行；不将来源不明旧题录充当新输入。
4. 文献outline.pdf导入及打开 → 大纲 → 高亮 → 标注定位；只阻塞真正依赖链。原选区解释/翻译仍独立用其冻结PDF及采证协议。
5. 普通完成会话可复用到历史搜索与任务分支；排队单独两消息，不复用原停止Check的中断会话；标签切换只用已经打开的本轮对象。
6. 全局搜索三个域独立执行；已有文献要先正常关联本轮项目，不能直接写索引或库制造搜索结果。未核跨项目隔离则仅报告实际项目内范围。
7. 配置类点最后执行，核恢复原值；未知目录删除、未授权上传/安装/共享设置变更立即停止受影响分支并记录现场，不修改规则消除阻塞。

## 冻结与报告

先提交必要资产，再分别运行macOS/Windows原样preflight，冻结源提交、点/方向修订、主用例与必需变体、每项Check及所有输入摘要。冻结目录不放在会反向参与自身摘要的场景内，不覆盖旧版本。

未来执行另核运行前提与预算，业务时限按第三档明确约定，不能默认套用P0的30分钟。未就绪保留74点完整分母；已执行缺证为inconclusive，未执行为not_evaluated，确证失败保留fail，不能边测边补资产或重试洗绿。

报告先简洁结论、方向一行四列表，再逐用例及Check明细；阻塞现场图在首、处理结果次之、辅助图最后。“全部原图”直达独立图集，“现场说明”直达独立证据说明，预览直达原图；缺图如实说明，所有本地链接使用可直接打开的绝对路径，保留历史报告。
