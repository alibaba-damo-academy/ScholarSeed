# Driver 可见任务

只读取本文件、本轮授权参数与真实 UI 观察，不读取 `judge.md` 或隐藏参考。仅操作已核身份的本轮隔离 Desktop 与任务拥有项目，不发送产品模型请求，不调用项目内部 IPC/API，不删除项目。

按本轮选择独立执行相应任务；没有前提或授权时记录缺口并继续其他独立获准任务，不自动扩展范围。

- 创建：取得本轮唯一合成名称与获准目标位置，从真实项目中心打开新建项目表单，填写并提交。观察实际结果，记录新增卡片、进入后的工作台与项目身份；不要只记录点击回执或提示。
- 切换：取得两个已准备好不同资料标记的隔离项目，分别从项目卡片进入各自工作台，打开资料库并记录实际项目及标记正文，再切回首个项目。缺少可区分资料时只记录已见切换，不能自行补造隔离结果。
- 接入：仅在允许创建及向获准既有合成目录写入项目元数据时，从新建表单选择已有目录。按 desktop-control 的当前原生选择器流程核对目录路径、URL 与可提交状态后确认；返回表单核对再提交，记录实际关联根路径和目录内资料。宿主能力或权限不足时停下，不替换成复制导入。
- 取消：使用另一唯一候选名称，记录创建前列表。打开已有目录选择后用可见控件取消，再取消整个创建表单；回到项目中心记录候选名称是否形成项目，不执行创建或删除。

项目标记、目录与截图不得含秘密。保留同一构建、实例、动作和项目的原始证据，原生输入记录实际 API/参数、前后状态和错误。不要假定固定等待等于完成；预算到界停止新动作并交接已发生状态与未观察分支，不作通过判定。
