# PROJ-01 候选判据：A 类事实核验

无获批正式 PRD/Check；冻结本文件版本后，仅对本轮所选点及其 Check 给 `pass / fail / inconclusive / not_evaluated`、理由与原始证据。A 类事实由 Observer/测试 Owner 核验，不需要语义模型评分。本文件不交给 Driver。只有入口或源码线索不算实际结果，未执行分支不追认为通过。

1. **PROJ-CREATE｜A：创建后进入对应项目（必需）**。真实创建动作后出现与本轮唯一名称一致的卡片，进入该卡片后工作台身份与实际创建项目一致，名称及根路径/项目身份可关联同一动作。创建到别的项目或明确错误为 `fail`；已执行但只有提示、卡片无对应工作台或身份缺失为 `inconclusive`；未获创建授权或未执行为 `not_evaluated`。
2. **PROJ-SWITCH-SCOPE｜A：切换后的资料范围（必需）**。两个本轮隔离项目已有独立、内容不同的资料标记；实际 A→B→A 切换时，每次工作台与打开资料的身份及正文都属于所选项目，未把另一项目资料当作当前范围。可复核的跨项目范围混淆为 `fail`；只有标题/卡片变化、两项目均为空或缺资料身份为 `inconclusive`；没有两项目前提或未执行为 `not_evaluated`。
3. **PROJ-ADOPT｜A：确认关联获准已有目录（必需）**。原生面板确认所选规范目录，表单提交后实际项目关联同一目录，既有合成资料身份与预先清单对应。关联其他目录、默认新目录或用复制导入替代为 `fail`；只见选择器关闭或表单路径而无关联终态为 `inconclusive`；原生宿主、目录写入权限或授权缺失而未提交为 `not_evaluated`。
4. **PROJ-ADOPT-CANCEL｜A：取消不创建项目（必需）**。有创建前列表、唯一候选名称、原生面板取消及整个创建表单取消的连续证据，返回后的列表不新增该候选项目且既有项目未被本动作修改。取消路径明确创建了候选项目为 `fail`；只见原生面板关闭而未证明整个创建已取消或列表缺失为 `inconclusive`；没有执行取消分支为 `not_evaluated`。不得删除项目以制造取消后的预期结果。

只汇总本轮所选点位的必需 Check；不让未选 P2 阻断 P1 子集，也不把未选项写成已完成。所选必需项存在失败即保留失败，无失败但证据缺失为 `inconclusive`，全未执行为 `not_evaluated`。每项通过仍只是候选判据下的本轮 A 类结果，不是正式覆盖或双平台验收。

5. **PROJ-ARCHIVE｜A：PROJ-ARCHIVE-01（必需）**。默认项目及其任务范围按归档状态隐藏，同ID对象与根资料仍保留并可恢复；不能以删除或改名代替归档，只有toast/卡片缺失不足。 有确证错误归属/丢失/重建冒充还原判fail；已操作但缺对象身份或前后正文判inconclusive；缺授权、原对象或未执行判not_evaluated。只操作本轮对象，不能删改产品或数据制造通过。

6. **PROJ-RESTORE｜A：PROJ-RESTORE-01（必需）**。同项目ID/根路径恢复，原任务ID、正文及资料摘要一致；不是重建同名项目，其他项目未被修改。 有确证错误归属/丢失/重建冒充还原判fail；已操作但缺对象身份或前后正文判inconclusive；缺授权、原对象或未执行判not_evaluated。只操作本轮对象，不能删改产品或数据制造通过。


## 第三档补充Check

7. **PROJ-EDIT｜A：修改项目元数据不串归属（必需）**。同一项目名称描述更新，原资料和任务仍属同一项目；不强加根路径绝不可变规则，身份或内容串项为失败。 必须保存同身份的前后状态、完整结果及结果原图；有确证错误为fail，执行但缺必要证据为inconclusive，缺前提/权限而未执行为not_evaluated，不把操作回执或单图当功能结果。

8. **PROJ-FILTER｜A：项目筛选及清空恢复（必需）**。筛选项目卡准确、打开同一项目，清空恢复原列表；任务卡联动无批准依据时单列观察，不追加要求。 必须保存同身份的前后状态、完整结果及结果原图；有确证错误为fail，执行但缺必要证据为inconclusive，缺前提/权限而未执行为not_evaluated，不把操作回执或单图当功能结果。

补充Check仅在选中P2点时执行；既有P0/P1判据不变。禁止改判据、降低要求、反复重试洗绿；新补测另开attempt，历史不覆盖。产品问题只留缺陷和证据，不改产品逻辑或规则。
