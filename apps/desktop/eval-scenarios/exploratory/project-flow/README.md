按钮、模型名称及静态文案只作本次观察线索，未经批准不成为精确文案要求或未来唯一 locator。后续改名先记录差异并核语义身份；无法确认时给 `inconclusive`，不只因旧名称消失判失败，也不改变按目标结果的候选功能判据。

运行前冻结目标构建、平台、隔离环境、项目/目录身份、来源与场景版本、动作授权和窗口。所有 Check 都是 A 类，由 Observer/测试 Owner 对实际状态和截图核验，无须产品模型或语义 Judge 请求。按档只执行对应点位；P1 不连带执行 P2 接入，未选择的点位不能算通过。已选点的缺前提分支保留 `not_evaluated` 和原因，不缩小冻结分母；确认接入与取消分别取证，不互相替代。

保存原始 UI 动作、项目身份、资料范围、必要原生日志和实际检查过的截图到本轮获准忽略目录；不把运行产物写入本场景。macOS 与 Windows 独立取证；本次 macOS 的观察不代表 Windows 已验证。不得使用内部接口、手写事件或静态截图替代真实流程。
