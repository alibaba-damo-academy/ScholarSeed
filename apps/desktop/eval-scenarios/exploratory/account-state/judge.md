# ACCOUNT-01 候选判据：A 类事实核验

暂无获批正式 PRD/Check。冻结本文件后由 Observer/测试 Owner 核实际所选点，逐项给 `pass / fail / inconclusive / not_evaluated`、理由及原始证据，不使用语义模型代判。本文件不交给 Driver；现成已登录状态不得作为本次真实登录的替代证据。

1. **ACCOUNT-LOGIN｜A：专用账户真实登录（必需）**。本轮从获准的隔离未登录状态开始，经实际应用内登录流程完成认证，返回客户端后账户入口显示本轮专用账户的正确身份，登录前后动作和实例可关联。明确显示错误身份或登录失败为 `fail`；执行过登录但缺起始状态、身份或返回客户端证据为 `inconclusive`；没有专用账户/权限或未执行为 `not_evaluated`。启动时已登录菜单、设置页可见或退出入口存在不证明本项。
2. **ACCOUNT-RESTORE｜A：本次登录后的状态保持（必需）**。先有本轮真实登录证据，再在明确记录的重新打开范围内核对同一专用账户仍有效；至少关闭并重开账户入口，若本轮明确要求客户端重开则必须有已授权的进程重开与恢复证据。实际丢失或切错身份为 `fail`；重开动作或同一身份无法关联为 `inconclusive`；未完成真实登录、无对应授权或未执行恢复步骤为 `not_evaluated`。面板重开不证明进程重开、令牌刷新或过期恢复，不能将未测试生命周期包装为通过。
3. **ACCOUNT-STATE｜A：当前账户菜单状态展示（必需）**。通过真实头像菜单观察当前已登录或未登录分支，有对应 UI 状态及身份遮挡证据；已登录时只核可见敏感身份按 UI 遮挡，不要求制造另一分支或执行登录、退出。可核实的错误状态或应遮挡身份明文展示为 `fail`；只有头像、缺实际菜单或分支身份不清为 `inconclusive`；未到达入口为 `not_evaluated`。只读当前分支可单独给结论，但须注明另一分支未观察；不推断认证有效性、登录或恢复已经验证。

仅按本轮所选稳定点汇总其必需 Check。只读状态不代替登录恢复，缺专用前提不改成产品失败，也不把缺证据写成通过。结论只适用于本轮实例、构建、平台及实际观察分支；候选判据不是批准 PRD、正式覆盖或 Windows 验收。
