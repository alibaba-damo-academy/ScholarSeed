# 账户状态：候选 A 类探索场景

方向 `ACCOUNT-01@2`，关联 `ACCOUNT-LOGIN-01@2`（P1）与只读 `ACCOUNT-STATE-01@1`（P2）。不改变默认 P0。没有获批正式 PRD/Check，所有预期均为探索候选，不能把已有登录菜单写成登录或恢复已通过。

按钮、模型名称及静态文案只作本次观察线索，未经批准不成为精确文案要求或未来唯一 locator。后续改名先记录差异并核语义身份；无法确认时给 `inconclusive`，不只因旧名称消失判失败，也不改变按目标结果的候选功能判据。

当前可见账户入口是头像菜单；设置中的账号设置导航不等于独立账户认证页。只读状态分支仅打开当前头像菜单，记录实际已登录或未登录分支及 UI 的身份遮挡，不登录、不退出、不触发积分或付费操作，也不为制造另一分支改用户状态。只观察当前分支即可描述该分支，另一分支须明确未观察。

完整登录恢复分支必须另有专用测试账户、可用登录环境、未登录的本轮隔离状态及本次登录授权；不得先退出真实用户或从其配置提取凭据。登录后的身份核对和重新打开账户入口分别留证；面板重开不代表客户端进程重开、令牌刷新或过期恢复。若本轮任务要求客户端重开，需明确生命周期操作授权和同身份恢复证据，不中断在途真实会话。缺少专用凭据或对应操作证据时原登录点保持 `partial`，完整用例不追认为已执行。

沿用 `scenario.json`、`cmd.jsonl`、`baseline.json`、`driver.md`、`judge.md`、`checks.json`。`cmd.jsonl` 只有状态预检，不是登录 UI runner；真实操作由获准 desktop-control Driver 按观察进行。`auth=none` 不预先要求登录，不代表绕过产品认证，也不提供账户或令牌。零产品模型回合与无需语义 Judge，不等于真实登录无外部副作用。

运行前冻结构建、平台、隔离环境、账户分支、所选点、登录/生命周期授权、预算与停止条件。`ACCOUNT-STATE` 与登录、恢复两个 Check 独立，A 类事实交 Observer/测试 Owner 核对。原始证据和截图只保存在本轮获准忽略目录，不存密码、验证码、令牌或完整敏感身份；敏感画面不直接展示。账户菜单缺截图时如实报告，不借另一步截图替代。macOS 与 Windows 各自留证，候选预期不形成正式覆盖。
