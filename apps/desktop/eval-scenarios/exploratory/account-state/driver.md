# Driver 可见任务

只读取本文件、本轮授权参数与真实 UI，不读取 `judge.md` 或隐藏参考。只操作本轮已核身份的隔离 Desktop，不读取真实用户凭据、不发产品模型消息。按明确选择分别处理只读状态或完整登录；不自行扩展分支。

只读状态任务：打开当前真实头像菜单，记录当前显示的已登录身份或明确未登录状态、产品原有的敏感身份遮挡及可见入口。不要假设有独立账户页，不点击登录、退出、积分、付费或其他账户变更入口。关闭菜单并保存同一观察的 UI 状态与截图；只概述身份，不记录完整手机号、邮箱或其他敏感标识。没有对应截图则说明缺口，不把另一画面当账户菜单。

完整登录任务：先核专用测试账户、登录环境、隔离未登录状态及本次登录权限。缺任何前提则停止，不退出当前用户以制造未登录态，也不借已有 token。由获准操作者沿本构建真实可见的应用内登录流程完成登录，不向记录输出密码、验证码或令牌。回到客户端账户入口核对该专用账户身份，关闭并重新打开账户入口记录状态。仅在明确要求且授权客户端重开的情况下才执行生命周期操作并记录重开后的同一身份；不从面板重开推断客户端重开已验证。

保留实际动作、账户分支、终态和已检查截图；敏感画面停止展示并说明获准证据入口。既有登录状态不是本次登录完成，登录完成也不是过期或刷新验证。预算到界停止新动作，交接缺前提与未观察分支，不作通过判断。
