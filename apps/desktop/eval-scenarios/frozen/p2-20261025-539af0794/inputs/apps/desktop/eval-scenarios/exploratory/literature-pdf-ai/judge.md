# 探索性判据：仅供独立 Judge 与人工复核

当前没有获批 PRD Requirement/Check ID。以下只是 `LIT-01` 的候选判据，不构成发布准入。运行前冻结本文件、fixture PDF 和方向行修订；本文件不交给 Driver、产品或文献导入目录。逐项给 `pass / fail / inconclusive / not_evaluated`、理由及本次原始证据指针；执行状态另列。缺必需证据时不能判通过。

## 参考事实（仅限合成 PDF 的 Pilot summary）

- 24 名志愿者使用每日笔记索引四周。
- 第四周，24 人中的 18 人在两分钟内找到目标笔记。这是一次观察结果，不是“提速 18%”或与对照组比较的效果。
- 没有对照组，检索表现只测量一次；不能据此确定索引**导致**检索更快，也没有长期效果证据。
- PDF 明示它是合成评测资料，不能被当作真实论文或对外研究结论。

## 逐项判据

1. **LIT-OPEN｜阅读和来源前提（A）**：产品文献全览中的实际条目、PDF 附件 ID、来源版本与本次 fixture 摘要可关联；真实阅读器显示一页正文，能选择该段文字。打开空标签、只见题录/文件名、资料库同名 PDF 或内置示例均不通过。若导入失败，后续 B 项为 `not_evaluated`。这是执行前提，不由 Judge 的语义分数替代。
2. **LIT-EXPLAIN｜选区解释（B）**：解释动作确实以该段非空英文选区和正确附件来源发起，任务到达可核终态并展示完整中文结果。解释须说清 24 人/四周的设计、18/24 在两分钟内找回的观察，以及无对照组、只测一次导致不能归因于索引的限制；允许合理归纳，但不得虚构随机分组、统计显著性、对照效果或长期效果。只是翻译原句、复述标题或任务“已完成”不足以通过解释质量。
3. **LIT-TRANSLATE｜选区翻译（B）**：翻译动作以同一附件的同一整段英文选区为源，目标为简体中文，任务到达可核终态并展示完整译文。译文须忠实保留 24 名志愿者、四周、第四周 18/24、两分钟、无对照组、仅测一次，以及不能推出索引造成提速的否定语义；不要求逐字对应，可自然表达。数字、条件、否定或因果关系反转为 `fail`，截断或原文范围不明为 `inconclusive`。
4. **LIT-EVIDENCE｜证据与副作用（A）**：两次动作各自的选区、页码、附件身份、实际模型/任务身份、完整结果和截图可与本次构建关联；没有未经授权的 PDF 字节写入、附件替换、重复导入或跨文献读取。无法读回完整原生结果或来源版本时列出缺口，不能用模型自述代替证据。

只在四项必需检查均有证据通过时给场景 `pass`。已有明确错误保留 `fail`；没有失败但证据不全为 `inconclusive`；未执行的动作单独记 `not_evaluated`。模型或 Prompt 变化需重新采集受影响的真实结果，不把本次输出自动写成新基线。
