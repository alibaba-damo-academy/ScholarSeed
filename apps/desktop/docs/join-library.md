# Add Search Results to the Literature Library

Status: current, 2026-09-18, branch `guide_subu`.

<a id="最终交互"></a>
## Final Interaction

The single-result action, bulk action, and AI conversation match card share the “Add to literature library” menu and call `pushLibItem()` through one path. In the all-library view, the menu order is Add directly, Add to my collections, then Add to project; the project option is hidden when there are no projects. In a project context, only Add directly and Add to my collections are shown, and the current project is linked automatically.
Collections support arbitrary nesting. Hover to expand and click to add to the selected node. “Create collection…” appears only at the top level of the collection list and the top level of a project's collection list, not at every level. Leaf collections have no expand arrow.
In the add-to-library menu's Create collection dialog, the name defaults to “未命名” and is fully selected; “创建到” defaults to “我的分类”. The dialog uses the existing Select component in a white floating surface. Creation from the all-library view can target only global collections; creation from a project can target only that project's collections.
After creation, refresh the sidebar, expand ancestors, and highlight the new collection for about 1.4 seconds. When creation starts from the add-to-library menu, add the current literature item to the new collection; creation from the sidebar does not add an item. If creation succeeds but adding the item fails, retry the add without creating the collection again.
After success, the row displays only “✓ 已加入”. The toast reports the count, such as “已添加1篇文献”, without showing the destination or a navigation action.
Submenus use the shared component's edge flipping and height limits. They support Esc, outside clicks, and closing through the dialog overlay. When the dropdown is open, Esc closes the dropdown first and leaves the dialog open.

## Engineering Mapping and Shared Changes

Reuse the existing DropdownMenu, Dialog, Input, Select, Button, Toast, and semantic tokens. The local-file/Zotero/BibTeX import flow, reader, and literature-detail layout were not changed. The check baseline was not adjusted.

It renders “仅元信息 / 元信息和全文” only when results came from an exact-search card and at least one selected paper has finished downloading; the supporting copy reports the downloaded count accurately. “元信息和全文” reuses only bytes that have already been downloaded. Serve's `apps/serve/service/literature/service/holdings.py` accepts either of two forms of evidence: a PDF that remains in managed storage after the current session downloaded it through the bridge, or a PDF that the Skill downloaded to its run directory and that a scoped read confirms exists. Attachment mounting uses the single attachment-domain entry point and does not download again. Serve directly rejects results from non-exact search sources. Failure to attach full text does not undo a successful metadata import. On completion, the UI reports “已加入 N 篇文献，其中 M 篇含全文” and separately reports the number without full text.
