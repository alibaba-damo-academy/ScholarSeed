# 科研任务指导

[English](SKILL.md) · **简体中文**

仅用于当前请求中的科研部分，不因词汇或工具相同而扩展到无关任务。
判断信息缺失前，先查看用户提供或引用的相关材料和此前回答。

## 检查意图，再按需加载细则

每个科研请求在实质执行前，都检查以下五项：

| 判断 | 检查内容 |
| --- | --- |
| 词义 | 当前语境是否已确定每个概念的含义？不擅自扩大或缩小。 |
| 关系 | 保留绑定短语，区分组合主题与并列主题；裸并列或以“和”连接的交叉领域可能仍有真实分歧。 |
| 前提 | 领域本身是否命名了两个实质不同、且用户尚未选择的阵营？必须能说出双方标准名称；仅宽泛不算分歧。 |
| 模式 | 预期交付物是否明确？实现同一交付物有多条路径，不代表用户意图不明确。 |
| 范围 | 聚焦程度是否足以完成该交付物？保留用户明确选择的广度，不违背意愿收窄。 |

只对均有充分合理性、且会实质改变工作的不同理解提问，即使其中一种更可能。
不制造分歧。无法确认的术语或没有可识别科研主题时，需要确认，不能编造事实；
宽泛主题本身有效。请求完整明确时直接路由，不额外提问；保留此前回答，
不能仅因切换技能就重新询问。

在询问未决分歧前，或不确定如何应用上述判断时，读取[澄清细则](references/clarification.zh.md)。
该文件负责提问顺序、可用模式选项、每轮一问和回答处理；否则不加载。
关键科研结论前读取[证据规则](references/evidence.zh.md)，仅问候或澄清时不加载。
只读一种语言版本；仍在上下文且未变的内容复用，内容变更或上下文丢失后补读。

## 尊重任务归属

本技能只提供共用科研指导，不是交付物或模式选项，不能再次路由到自身。
根据可用任务技能的实际范围、排除项和完成预期成果所需的工作选择，不只看最终格式。
使用匹配技能或必要的有序组合；成本可帮助选择匹配路径，不能否定技能覆盖范围。
只有明确交付物没有可用技能覆盖、且通用能力可以完成时，才直接使用通用能力。
能用通用工具完成，不等于没有技能覆盖。

将忠实意图带入选定技能的流程：保留动机、绑定关系和用户给出的每个具体约束，
不增加用户未说明或未授权代选的内容。双向核对遗漏与无依据添加。
该记录留在内部；简短告知用户将做什么，再依次遵循选定技能，不虚构技能调用 API。

具体任务技能拥有阶段、模式、检查点、授权和恢复规则。意图澄清不等于授权启动、
下载或发布；本技能不复制或覆盖这些协议。
内部分类和路由推理不对外展示，但应解释证据限制、真实执行模式、成本和必需确认。
遵守宿主当前检索限制，加载技能不授权外部检索。

用户转为非科研任务时，停止科研专属澄清和结论格式；历史中保留的指令不延伸适用范围。
