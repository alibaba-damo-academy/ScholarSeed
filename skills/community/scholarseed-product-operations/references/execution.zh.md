# 执行环境

[English](execution.md) · **简体中文**

执行本地代码或安装依赖前读取，适用于科研计算、数据处理、文件转换和软件开发。
本指南只负责环境使用，不负责研究方法，也不授予权限。实际任务没有需要时，
不加载检索、文献库、计划或 Bridge 流程。

## 使用会话环境

用户 Python 代码和依赖安装使用会话 cwd 绑定的 venv，包括注册项目之外的会话。
除非用户当前消息已显式指定要运行的解释器或命令路径，否则默认使用宿主提供的
SCHOLARSEED_TASK_PYTHON 解释器或会话 python 命令；安装使用该解释器的 `-m pip`，
不使用其他 pip 可执行文件。Shell 内 `cd` 不会切换环境。
只检查任务所需的解释器或依赖信息，不读取凭据和无关配置。

任务环境缺失或损坏时，不回退产品 Python，也不修改全局 Python 设置。
报告失败命令和实际错误，停止依赖执行。不猜测替代环境、不激活其他项目 venv，
不静默修复宿主。

`scholarseed-skill-python` 仅供已准入随包 Skill 按自身说明执行脚本；
不是任意用户代码的解释器、安装目标，也不是任务环境不可用时的替代品。
不把用户脚本复制到随包 Skill 目录以获取该环境。

## 按范围执行

现有依赖足够时直接复用。只安装获准任务实际需要的依赖，遵守网络和写入限制；
依赖安装不授权全局升级或修改其他项目。按实际 Shell 的引用及参数约定，
将文件路径和 URL 作为数据处理；不在 Windows 假设 POSIX 路径或可执行布局。
保留输入，遵循给定工作及输出目录，不覆盖其他会话成果。
优先有界读取和相关文件/文本搜索，不把大文件整份送入上下文；
使用实际可用工具，不强制依赖未核验的可执行文件。

搜索文本或文件时，可用则优先使用 `rg` 或 `rg --files`；不可用时使用已有替代工具。
不要仅为输出大段文件内容而编写 Python 脚本。对于网络下载、依赖安装或较慢的文档解析命令，
应设置充足的等待窗口（如 `yield_time_ms` >= 30000，仍在运行且无新输出时退避至 60000–120000），
避免以 1–5 秒短间隔反复空轮询 `write_stdin` 或在正常传输途中提前中断进程。

核验请求的结果，而非只看退出码；如实报告未完成的执行或验证。
项目修改及测试遵守[项目指南](project.zh.md)，生成文件交付遵守
[文件交付指南](scholarseed-bridge/guides/artifacts.md)。研究方法、证据解释和业务检查点
仍归对应科研或任务 Skill。
