# 产物与工作台组件

[English](workbench.md) · **简体中文**

产物使用原生文件卡和工作台，不通过 OpenUI 生成产物卡。没有独立的产物预览或选择 slot。

## 先生成并发布真实产物

遵循[文件产物指南](../../scholarseed-bridge/guides/artifacts.zh.md)和随包 artifact/publish 契约。
文件写入当前获准工作目录，发布前检查内容、类型和完整性。每个文件保留独立回执与对象身份；
多个文件分别发布，部分成功不算全部成功。

原生文件卡、图片查看、版本、打开/保存、系统应用菜单和工作台导航归宿主。
优先使用真实发布回执生成的原生卡；通用插件没有任意文件或外链访问权限，
不得调用宿主 DOM、HTTP 或文件系统，也不能伪造菜单结果。

## 使用原生文件卡和分组

原生卡来自真实发布回执，宿主按原顺序显示多个文件和文件夹。
手写路径或示例版本不替代回执。权限检查、版本匹配内容和打开动作归宿主；React 导出不是可直接调用的公共 slot。

真实图片使用产物图片预览，任意 URL 不代表获准资产。Lean 文件可在编辑器显示，
但编辑、语法高亮和预览不等于证明验证。用户要求形式化验证时，遵循可用的 formal-verification
技能及其真实授权和服务契约，不假定工作台提供诊断服务。只有真实证据支持所交付版本时才能报告验证；
验证不可用或版本不匹配必须明确说明。示例目标或诊断不是证明，预览也不证明文件可访问或工作台已打开。

可与其他对话卡组合，复用原产物与回执。保存、导入、覆盖和系统操作仍须实际宿主权限，加载技能不授予权限。
