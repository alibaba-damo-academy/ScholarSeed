# 计划 Bridge 回退

[English](fallback.md) · **简体中文**

仅产品计划已启用而本轮尚无专用工具，或旧产品 Schema 需要 Bridge 对齐时读取。
原生轻量步骤本身不要求这条路径或产品树。

已有产品树继续由产品服务管理。使用打包的 scholarseed_bridge plan/get、plan/structure、plan/action 契约；
仅缺失或过期时发现契约。Bridge 使用 capability/operation/request，不能与原生计划参数或专用产品工具混用。
不通过 Shell 脚本调用产品操作，不检查或注入 Bridge 凭据。

读取 [Bridge 协议](../../README.zh.md)，按需选择完整目标契约。变更前读取当前状态，使用真实 ID、revision 和允许动作。
保留原计划树、授权与用户检查点。工作前开始，只有观察证据后才完成；未记录的工作不编造开始或耗时。
如实报告剩余或失败阶段，回执不等于任务验收。
