# Skill Ownership

Development workflow Skills and their host instructions are maintained in private supplements,
not in the public source checkout. They are optional for source contributors.

Product Skills remain in [`skills/community/`](../../skills/community/).
See [packaging and discovery boundaries](../architecture/skills.md),
the [development guide](../../CONTRIBUTING.md) and [developer documentation](../../developer-docs/README.md).

## 中文

开发 Skill、宿主说明及流程导航只在文档内源仓维护，不作为公开源码开发的必需依赖。
产品 Skill 继续由源码仓管理；产品打包、发现与验收门禁不因开发 Skill 内迁而取消。
